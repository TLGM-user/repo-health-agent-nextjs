## FAQ (for landing page)

**Q: How is this different from GitHub's built-in security features?**
A: GitHub provides alerts, but GitFlow aggregates them across all repos, adds dependency freshness and test coverage analysis, opens automated fix PRs, and tracks trends over time.

**Q: Does it support private repos?**
A: Yes. GitFlow uses GitHub App installation tokens, so it works with both public and private repositories.

**Q: What languages/frameworks are supported?**
A: We detect manifests for npm, PyPI, Go modules, Cargo, Ruby gems, and PHP Composer. Language-agnostic test detection.

**Q: Can I try it before paying?**
A: Yes. The free plan includes 1 repo with on-demand scans and basic health scoring. No credit card required.

**Q: How does Enterprise pricing work?**
A: Contact us at hello@gitflowanalytics.dev. Enterprise includes SSO/SAML, custom integrations, dedicated support, SLA guarantees, and custom contracts.
